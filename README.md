# SAVORA — Responsive Restaurant Landing Page

A modern and responsive restaurant landing page created for The Sky Gen Web Development Project 02.

## Business Concept

SAVORA is a fictional modern restaurant focused on memorable dining, fresh cuisine, warm hospitality, private events, takeaway, and celebrations. The website provides visitors with information about the restaurant, services, menu plans, customer reviews, FAQs, and a reservation/contact section.

## Features

- Sticky responsive navigation bar
- Smooth scrolling navigation
- Active navigation link highlighting
- Mobile hamburger menu
- Full-screen hero section
- Call-to-action buttons
- About restaurant section
- Service cards with hover effects
- Three pricing/menu plans
- Highlighted recommended plan
- Testimonials carousel with arrows and indicators
- FAQ accordion with JavaScript
- Reservation form with JavaScript validation
- Embedded Google Map
- Clickable social media icons
- Responsive design for desktop, tablet, and mobile
- Modern restaurant-focused UI
